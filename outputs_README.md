# Outputs

This folder stores the plots generated by the CyberSentinel notebook.

All files here are **auto-generated** — run the notebook to produce them.

| File | Description |
|------|-------------|
| `cybersentinel_eda.png` | EDA: class distribution, URL length boxplot, feature correlation heatmap |
| `cybersentinel_confusion.png` | Confusion matrices for Random Forest and SVM |
| `cybersentinel_roc.png` | ROC curves with AUC scores for both models |
| `cybersentinel_features.png` | Top 15 feature importances (Random Forest) |

These files are excluded from version control via `.gitignore`.
